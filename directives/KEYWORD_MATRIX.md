## 1. Executive Recruiter Rules for Keywords
1. **Qualifications > Simple Buzzwords**:
   * A standalone buzzword ("Python") gets scanned, but a recruiter takes **15 seconds** to verify **HOW** and **WHY** you used it.
   * Format: $\textbf{[Action Verb in Past Tense]} + \textbf{[What]} + \textbf{[How / Tech Stack]} + \textbf{[Result or Reason]}$.
2. **No "Hot Dogs" (Vanity Metrics)**:
   * Recruiters reject early-career brags about "monetization", "millions in revenue", or startup marketing claims as fluff ("hot dogs").
   * Replace with boring, rock-solid engineering qualifications: microservice design, database migration safety, API response latency, and team collaboration.
3. **The 75% Rule**:
   * Collect 10–15 JDs for the target title.
   * Tally the most common required competencies.
   * Place **75% of your target keywords in the top half of page 1**.

## 2. Software Engineering (SWE) Intern & Entry-Level Matrix

### A. Core Programming Languages & Paradigms
* **Languages**: Python, Java, C++, TypeScript, JavaScript, C#, Go.
* **Concepts**: Object-Oriented Programming (OOP), Data Structures & Algorithms, Clean Architecture, Design Patterns, Multithreading, Concurrency basics.

### B. Backend & Web Frameworks
* **Frameworks**: Spring Boot (Java), FastAPI (Python), Django, Node.js / Express, React, Next.js, HTML5, CSS3.
* **Architecture**: RESTful APIs, Microservices, CRUD operations, JSON serialization, Client-Server architecture, Webhooks.

### C. Databases & Data Modeling
* **Relational**: SQL, PostgreSQL, MySQL, SQLite.
* **NoSQL**: MongoDB, Redis (caching).
* **Practices**: Database migrations, indexing, schema design, ACID transactions, ORMs (SQLAlchemy, Hibernate, Prisma).

### D. Cloud, Infrastructure & Tooling
* **Version Control**: Git, GitHub, GitLab, branch workflows, Pull Requests, Code Reviews.
* **Containers & Cloud**: Docker, Linux (bash/command line), AWS (S3, EC2, Lambda), Google Cloud Platform (GCP), Azure.
* **Methodologies**: Agile, Scrum, Jira, CI/CD pipelines (GitHub Actions), Unit Testing (`pytest`, `JUnit`, `Jest`).

### E. Mandatory Non-Technical / Behavioral Qualifications (From Recruiter Spec)
* **Ability to work with others** (Pair programming, cross-functional syncs).
* **Takes direction and criticism** (Implementing feedback from senior engineers and code reviews).
* **Clear technical communication** (Explaining code choices in meetings).

## 3. AI Engineering & Machine Learning Intern Matrix

### A. Foundational Software & Languages
* **Languages**: Python (Advanced), TypeScript / JavaScript, SQL, C++.
* **SWE Core**: REST APIs (FastAPI / Flask), Git, Docker containerization, Linux, Cloud deployment (AWS / GCP / Modal / Railway).

### B. Generative AI, RAG & Agentic Systems
* **RAG (Retrieval-Augmented Generation)**: Chunking strategies, semantic search, dense & sparse embeddings, hybrid search.
* **Vector Databases**: FAISS, ChromaDB, Pinecone, Qdrant, FastEmbed, pgvector.
* **LLM Tooling & Frameworks**: LangChain, LangGraph, LlamaIndex, LiteLLM, Ollama, Hugging Face Transformers.
* **AI Coding & Productivity Tools**: ChatGPT, Claude, GitHub Copilot, Codex AI, Cursor.
* **Techniques**: Prompt Engineering, structured outputs (JSON schema), function calling, tool use, LLM evaluation, hallucination mitigation.

### C. Traditional Machine Learning & Deep Learning
* **Libraries**: PyTorch, TensorFlow, Scikit-Learn, NumPy, Pandas, OpenCV.
* **Algorithms**: Neural Networks, CNN, LSTM, Transformers, XGBoost, Random Forest, Logistic Regression, Reinforcement Learning (PPO).
* **Metrics & Evaluation**: F1-Score, Precision, Recall, ROC-AUC, Loss functions, Inference Latency, Model Optimization, Quantization.

### D. Mandatory Non-Technical Qualifications (From Recruiter Spec)
* **Explain technical concepts to non-technical people** (Translating model performance, precision/recall, and RAG retrieval accuracy into clear business terms for product managers and stakeholders).
* **Take direction and constructive criticism** (Iterating on prompt architectures and algorithmic baselines according to senior lead recommendations).
* **Collaboration & Scientific Humility** (Working well with researchers, software engineers, and domain specialists).
